# LUMINA website (HTML + CSS + JS)

Files: `index.html`, `style.css`, `app.js`, `images/`.

## Edit
- `app.js` (top): `CONFIG.whatsapp` (number with country code, digits only), and the `P` product list (name, price, description, colors). Prices are placeholders.
- Real photos: put them in `images/` and add `img:"images/photo.jpg"` to a product.
- Colors are at the top of `style.css`: `--green` = Deep Forest Green #063D2A, `--gold` = Champagne Gold #FFC928, `--bg` = Soft Cream #F5EFDF.
- Logo: `images/logo.png` (transparent LUMINA logo) is shown in the green header. `images/lumina-square.jpg` is used for sharing and the app icon.

## GitHub Pages
Upload everything to a repository, then Settings → Pages → Deploy from a branch → `main` / `(root)`.
